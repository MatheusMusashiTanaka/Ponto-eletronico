# Sistema de Ponto Eletrônico

## Visão Geral

Este arquivo é um sistema de ponto eletrônico usado para registrar e gerenciar os horários de entrada, saída e intervalos dos colaboradores de uma organização. O sistema visa automatizar o controle de jornada de trabalho, oferecendo uma forma eficiente e segura de acompanhar a assiduidade dos funcionários, gerar relatórios e garantir conformidade com as normas trabalhistas.
